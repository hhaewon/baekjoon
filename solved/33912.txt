R[i] : i번 횡단보도 순서 : 즉 나머지 
순회하면서 앞 보다 큰 다음 나머지 갖는 수 생성 N*k+R[i] >= time, k>=(time-R[i])/N
N(k-1)+R[i] < time -> k < (time-R[i])/N + 1


CW time = 0;
for (int i = 1; i<M;i++) {
    k = (time-R[i])/N + 1
    time = N*k+R[i]
}

CCW time=0
for (int i = N; i>=M;i--) {
    k = (time-R[i])/N + 1
}
